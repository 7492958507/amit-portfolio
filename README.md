# Amit Kumar — Modern 3D Personal Portfolio

> **Live Deployment:** [https://7492958507.github.io/amit-portfolio/](https://7492958507.github.io/amit-portfolio/)  
> **GitHub Repository:** [https://github.com/7492958507/amit-portfolio](https://github.com/7492958507/amit-portfolio)

A modern, high-performance personal portfolio website for **Amit Kumar** (Software Engineer & Full-Stack Developer) featuring interactive 3D WebGL background effects, 3D perspective tilt cards, custom interactive boy avatar with real-time cursor eye tracking, full ATS resume viewer, and owner administration mode.

---

## 🚀 Tech Stack

- **Frontend Framework:** React 19 + TypeScript
- **Build Tool:** Vite 8
- **3D Graphics & Animations:** Three.js, Canvas Confetti
- **Styling:** Tailwind CSS, Lucide React
- **Validation & Security:** Cloudflare Turnstile, Honeypot bot protection, PIN-based owner auth

---

## 🛠️ Features

- 🌌 **Interactive 3D WebGL Universe:** Rotating wireframe Torus Knot and Icosahedron responding to mouse parallax.
- 🧑‍💻 **Interactive Boy Avatar:** Hand-crafted SVG avatar with pupil tracking cursor motion and automatic eyelid blinks.
- 💼 **Experience & Projects:** Showcase of production systems, Heloix InternFlow, AI Support Ticket platform, and HireSense AI.
- ⚡ **Technical Skills Bento Grid & Icon Cards:** 30+ technologies with official SVG brand logos.
- 📄 **ATS Resume & LaTeX Viewer:** Built-in viewer with copyable LaTeX code and PDF download.
- 🛡️ **Owner Administration Mode:** Protected with secure PIN authentication to edit portfolio content on the fly.

---

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/7492958507/amit-portfolio.git

# Navigate to directory
cd amit-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

---

## 📦 Build for Production

```bash
npm run build
```
